## Реализовано

- **Лента постов** — бесконечная прокрутка, новые посты подгружаются при скролле вниз
- **Обработка ошибок** — при сетевой ошибке отображается экран с иллюстрацией и кнопкой возврата
- **Платный контент** — отдельный кейс для постов с ограниченным доступом
- **Разворачиваемый текст** — длинные превью обрезаются до 2 строк с градиентом и кнопкой «Показать ещё»
- **Лайки** — можно поставить и убрать лайк на пост

## Стек

- **React Native** + **Expo**
- **expo-router** — навигация
- **Axios** — HTTP-клиент
- **TanStack React Query** — кеширование запросов, бесконечная пагинация, управление состоянием загрузки и ошибок

## Почему без MobX

Необходимости в глобальном стейт-менеджере не было — TanStack React Query полностью закрывает работу с серверным состоянием (загрузка, ошибки, кеш, пагинация), а локальный UI-стейт решается через `useState`.

## Запуск

```bash
pnpm install

# Android
npx expo start --android

# iOS
npx expo start --ios
```
